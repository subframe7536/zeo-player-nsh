## 设计决定（已定，不要改）

- **不引新依赖**，自写最小实现 `src/i18n.rs`：
  ```rust
  //! 界面语言：简体中文 / English。字符串就地双语（`tr!("播放", "Play")`），
  //! 当前语言是进程级原子量，界面、托盘、引擎错误都能读。

  #[derive(Debug, Clone, Copy, PartialEq, Eq)]
  pub enum Lang { Zh, En }

  pub fn lang() -> Lang            // 读 AtomicU8
  pub fn set_lang(lang: Lang)      // 写 AtomicU8

  /// 系统语言标签（`zh-Hans-CN`、`zh_TW`、`en-US`…）→ 界面语言：`zh` 开头为中文，其余英文。
  pub fn from_locale(tag: &str) -> Lang

  #[macro_export] macro_rules! tr {
      ($zh:literal, $en:literal) => { match $crate::i18n::lang() { $crate::i18n::Lang::Zh => $zh, $crate::i18n::Lang::En => $en } };
  }
  /// 带参数：`trf!("{} 首", "{} tracks", n)`。
  #[macro_export] macro_rules! trf {
      ($zh:literal, $en:literal, $($arg:tt)*) => { match $crate::i18n::lang() { $crate::i18n::Lang::Zh => format!($zh, $($arg)*), $crate::i18n::Lang::En => format!($en, $($arg)*) } };
  }
  ```
  只有两种语言，就地双语比键值表更好维护（中文原文就在调用处，编译期保证两种都写了）。英文复数用简单规则（`1 track` / `2 tracks`）时可以用 `if n == 1 { … } else { … }`，不做通用复数框架。
- **设置**：`LibraryConfig.language: Language { System, Zh, En }`（默认 `System`），设置 →「外观」新增「语言」下拉（选项名固定写本语言：`跟随系统` / `简体中文` / `English`——「简体中文」「English」两项不翻译）。
- **切换生效方式**：切换语言时整棵界面重建（语言切换很少发生，重建最简单可靠）。`Store` 加 `lang: Signal<Lang>`；`App()` 里把 `root` 的内容包进 `dynamic(move || { s.lang.get(); … })`（与「隐藏到托盘时拆掉界面」同一思路），设置弹窗、其它弹窗也在里面，切换后设置弹窗停留在「外观」分类。托盘菜单在语言变化时重新 `apply`。
- **跟随系统**：`App()` 启动时读 `nsh_core` 的环境 `locale()`（`nsh_core::element::ambient::locale()`，返回 `Locale`，`as_str()` 取标签）→ `from_locale`。只在启动和切到「跟随系统」时判断，不监听系统语言变化。
- **哪些要翻译**：用户能看到的一切——界面文字、无障碍标签（`.label(…)` / `.accessibility_label(…)`）、占位符、提示、弹窗、菜单、托盘菜单与提示、显示在界面上的错误（引擎 `set_error`、`add_root` 的错误、文件操作提示）。
- **哪些不翻译**：`eprintln!` 日志；代码注释与 README 正文（README 加英文的语言说明一句即可）；测试里的断言文案（测试固定中文运行，见下）；LRC 解析里的数据规则（如识别「作词」「作曲」等元数据行的关键字——那是歌词内容，不是界面）；`Unknown Artist` / `Unknown Album` 这类写进缓存的缺省值（保持现状，避免缓存随语言变化）。
- **测试固定中文**：`tests/ui.rs` 的 `isolate()` 无论有没有语料都写 `library.json`，带 `"language": "zh"`；headless 环境的默认 locale 是 `en-US`，不固定的话现有断言全会失败。

## Steps

### Step 1：基础设施

1. 新建 `src/i18n.rs`（按「设计决定」），`src/lib.rs` 加 `#[macro_use] mod i18n;`，**放在所有其它 `mod` 声明之前**（`macro_rules!` 按声明顺序生效，放后面的话前面的模块用不了 `tr!`）。
2. 单测 `i18n_from_locale`：`zh-Hans-CN`、`zh_CN`、`zh-TW`、`zh` → `Zh`；`en-US`、`ja-JP`、空串 → `En`。单测 `i18n_macros_follow_lang`：`set_lang(En)` 后 `tr!("播放","Play") == "Play"`、`trf!("{} 首","{} tracks",3) == "3 tracks"`，测完 `set_lang(Zh)`。（这两个测试改全局原子量，放同一个用例里串行执行，避免与其它测试竞争——若担心并行，用 `std::sync::Mutex` 包住。）
3. `LibraryConfig` 加 `#[serde(default)] pub language: Language`（`enum Language { #[default] System, Zh, En }`，`serde(rename_all = "lowercase")`）+ getter/setter；`LibraryState` 加字段；`Store` 加 `lang: Signal<Lang>`；`store::set_language(Language)`：保存、算出 `Lang`（System 用 `locale()`）、`i18n::set_lang`、`s.lang.set`。
4. `App()`：`store::install()` 之后、建界面之前，按配置算出语言并 `set_lang`；把 `root` 下的子树（`when(!hidden, shell)` 与各弹窗）包进 `dynamic(move || { s.lang.get(); … })`，保持原有挂载顺序与条件。
5. `tests/ui.rs` 的 `isolate()`：总是写 `library.json`，没有语料时内容为 `{"language": "zh"}`，有语料时在现有 JSON 里加 `"language": "zh"`。

**Verify**：`nsh check .` → exit 0；`nsh test .` → exit 0（此时界面还全是中文，测试应全绿）。

### Step 3：设置搜索双语

- `Section.title` 改为 `fn() -> &'static str`（返回 `tr!(…)`），或保留 `(&'static str, &'static str)` 二元组并加 `fn title(&self) -> &'static str`——选后者（`const SECTIONS` 里不能调宏）。

规则：
- 字面量 `"播放"` → `tr!("播放", "Play")`；`format!("{} 首", n)` → `trf!("{} 首", "{} tracks", n)`。
- 需要 `&'static str` 的地方（如 `setting_section(title: &'static str, …)`、`empty_state(…, &'static str, …)`）——`tr!` 返回的就是 `&'static str`，可直接传。
- 需要闭包的文本（`text(move || …)`）在闭包里调 `tr!`。因为切换语言会整树重建，静态文本也会更新。
- 英文风格：句首大写、按钮用动词短语（`Add folder…`、`Rescan`、`Delete file…`）、菜单省略号用 `…`；术语统一：曲库 Library、曲目 Track(s)、歌手 Artist(s)、专辑 Album(s)、标签/流派 Genre(s)、歌单 Playlist(s)、智能歌单 Smart playlist、我喜欢 Liked、全屏播放 Now Playing、托盘 tray（macOS 菜单栏 menu bar）、封面 Cover、歌词 Lyrics。
- 不要顺手改中文原文（测试依赖它们）。

**Verify**：每组后 `nsh check .`、`nsh test .` → exit 0。
