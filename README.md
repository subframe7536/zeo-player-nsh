# Zeo Player

本地优先的桌面音乐播放器，原生界面、低资源占用。支持 macOS 与 Windows。

支持格式：MP3、FLAC、WAV、AIFF、M4A（AAC / ALAC）、AAC、OGG Vorbis。

## 功能

### 曲库

- 支持多个音乐文件夹：用系统文件夹选择器添加，或直接把文件夹 / 音频文件拖进窗口（已在曲库里的会自动定位到它所在的文件夹）。
- 扫描时显示实时进度；可随时「扫描更新」或「重建曲库」（重读全部标签与封面）。
- 文件夹监视（可选）：文件夹里的音频文件增删或改名后，曲库自动更新。
- 流派标签分隔符可自定义（支持多个），修改后立即重新拆分，带预览。
- 封面/歌词可以来自曲目同目录的同名图片/lrc（jpg / jpeg / png / webp）或内嵌元数据。
- 过滤低于时长 / 大小阈值的音频，不进曲库。

### 浏览与搜索

- 四个视图：文件夹（左侧目录树只列文件夹、可折叠，右侧显示选中文件夹直接包含的曲目；把曲目行或文件夹行拖到树里的某个文件夹上即移动位置，拖错会提示；文件夹上右键可新建子文件夹、重命名、删除——删除按「删除文件」设置走回收站或直接删除，曲库根右键是「从曲库移除」不动文件）、歌手（头像网格）、专辑（封面网格）、标签，大曲库也流畅滚动。
- 曲目列表双击播放；行尾爱心按钮直接收藏 / 取消收藏。序号列（`#`）只在专辑详情里显示曲目号；设置 →「封面」→「在列表中显示封面」关掉后，曲目表封面列、网格卡片、头像、标签与队列行里的封面位整格移除（不画占位图）。
- 曲目右键菜单：播放、添加到歌单、重命名文件（只改主文件名，扩展名不变）、在访达中显示，以及「从曲库中删除」（只删记录与缓存，文件还在时下次扫描会重新入库）和「删除文件…」（确认后移到回收站；设置 →「曲库」→「删除文件」可改成不经回收站直接删除）。
- 侧栏顶部的搜索框匹配标题、歌手、专辑和文件名；点框外任意位置即失焦。
- 窗口变窄时界面自适应：侧栏收成图标栏（点放大镜展开完整侧栏浮层，失焦 / 选中后收回），曲目表的专辑、大小、序号（仅专辑详情）列按宽度逐级收起，播放条隐藏时间数字、音量滑条收成音量键的竖向弹层；全屏播放页的封面随窗口缩放，设置弹窗左栏也收成图标。

### 歌单

- 手动歌单：在曲目上点右键（或全屏页「⋯」）→「添加到歌单」。歌单页里右键可移除；文件被移走后条目保留，回到曲库时重新出现。
- 智能歌单：按条件从曲库自动聚合，曲库变化时跟着更新。条件分元数据（标题、歌手、专辑、专辑歌手、标签、年份）、音频（格式、时长、采样率、比特率、声道数）、文件（文件夹、文件名、大小、修改时间）三组；组合方式为「全部」或「任一」，可排序并限制数量，编辑时实时显示匹配数。
- 侧栏「+」新建；右键歌单可重命名 / 编辑条件、删除（删除前确认，不动文件）。
- 固定的「我喜欢」排在歌单最前；曲目行尾、播放条与全屏页上的心形按钮收藏 / 取消收藏曲目。

### 播放

- 上一首 / 下一首、循环模式、精确跳转；播放键图标在播放三角与暂停竖条之间形变过渡。
- 播放条右侧的队列按钮弹出当前队列，点一首直接跳过去；点外面或 Esc 关闭。
- 淡入淡出（设置里输入 0–5000 毫秒，0 为关闭，默认 200 毫秒）：播放、暂停、切歌、跳转时音量渐变；一首自然播完接下一首时不淡变。
- 输出设备变化（拔下耳机、切换系统默认设备）时自动暂停，可在设置 →「播放」→「输出设备」关闭——关闭后会在新的默认设备上继续播放；设备全部断开时总会暂停。
- ReplayGain：按曲目或按专辑标签调整音量，可设预放大、无标签曲目的增益与防削波（设置 →「播放」，默认关闭）。
- 10 段均衡器（31 Hz–16 kHz，±12 dB）与前级增益：竖排推子、左侧 dB 标尺，内置流行 / 摇滚 / 爵士 / 古典 / 人声 / 低音增强 / 高音增强预设，拖动立即生效（设置 →「播放」→「均衡器」）。
- 记住上次播放：重新打开时恢复曲目、位置和队列。
- 支持系统媒体键与锁屏控制（Now Playing），显示曲名、歌手 / 专辑与封面。Windows 上硬件媒体键随窗口激活归 Zeo（与其他用键盘钩子抢键的播放器并存时，最后聚焦的播放器拿键）。

### 全屏播放

打开时淡入上滑、收起时淡出下滑（跟随系统「减弱动态效果」设置）。

- 列表封面作背景，切歌时平滑过渡；左列大封面、曲名、歌手 / 专辑、音质与流派标签，「⋯」菜单可在访达中显示、拷贝路径。
- 波形进度条：可点击或拖动跳转。
- 行级歌词：同名 `.lrc` 文件优先，其次内嵌歌词（设置 →「歌词」→「歌词来源」可换成内嵌优先）。当前行自动跟随（停在偏上位置），手动滚动后 3 秒恢复跟随，点击某行直接跳转；左 / 居中 / 右对齐可选（默认左对齐）；歌词区上下边缘淡出，离当前行越远越模糊（鼠标移入时变清晰）；悬停行在行尾显示时间戳（占位不被长歌词盖住，设置 →「歌词」→「歌词行时间戳」可关闭）。
- 歌词偏移：全屏歌词区右缘的竖排控件，± 按钮按 0.5 秒步进调节当前曲目的偏移，点时间值弹出横向滑条可大范围拖动（正值提前、负值延后，±30 秒内，可一键重置），只对这首歌生效并随文件改名/移动保留；设置 →「歌词」→「全局歌词偏移」填毫秒，对所有曲目叠加生效（适合蓝牙耳机等固定延迟）；`.lrc` 文件自带的 `[offset:毫秒]` 标签也会生效。点击歌词行跳转时同样按偏移后的时间定位。
- 键盘：Space 播放 / 暂停，← → 快退 / 快进 5 秒，↑ ↓ 音量，Esc 收起。

### 外观与字体

- 浅色 / 深色跟随系统，也可在设置 →「外观」固定一种。
- 主题色：设置 →「外观」→「主题色」换按钮与选中态的强调色——默认「封面」自动跟随当前曲目封面的主色调，同时向界面底色轻调（切歌时 300ms 平滑过渡；黑白封面自动回黑白）。也可钉住黑白（shadcn 风格）或红 / 橙 / 绿 / 蓝 / 紫预设色。
- 界面字体：设置 →「外观」→「字体」可选系统默认或任一已安装字体，带搜索与逐字体预览，选一个立即生效。

### 设置

- 侧栏「设置」打开设置弹窗：左栏是分类与搜索框（直接搜选项），右栏是所选分类的内容；Esc 或点遮罩关闭。

### 托盘

- 第一次点关闭按钮时选择「最小化到托盘」或「退出」，选择会记住（设置 →「窗口」→「关闭窗口时」可改）。
- 最小化后播放继续；托盘图标本身是播放 / 暂停按钮：左键播放 / 暂停，右键打开菜单（可上一首 / 下一首、打开窗口、退出）。macOS 上是黑白的菜单栏图标、旁边显示当前曲名（放得下时连歌手）；Windows 上悬停图标显示当前曲名 — 歌手，双击打开窗口；macOS 上从 Dock 点开也恢复窗口。
- 可选「记住窗口大小和位置」：重新打开时恢复上次的窗口（设置 →「窗口」，默认开）。
- 只允许一个实例：已打开时再启动会激活已有窗口（最小化到托盘的也会显示出来）。

## 构建

需要安装 [NSH](https://nsh.dev) 与 [Rust](https://rustup.rs)：

```sh
nsh run .                          # 本机运行（改代码自动重建）
nsh package . --target macos       # 打包 .app（在 macOS 上）
nsh package . --target windows --icon resources/icon-windows.png   # 打包安装包（在 Windows 上）
```
