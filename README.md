# Zeo Player

本地优先的桌面音乐播放器，原生界面、低资源占用。支持 macOS 与 Windows。

支持格式：MP3、FLAC、WAV、AIFF、M4A（AAC / ALAC）、AAC、OGG Vorbis。

## 功能

### 首页

- 启动后的默认页：头部按时段问候（早上 / 中午 / 下午 / 晚上 / 夜深，各配一句文案），右侧是本周时长、新增收藏与连续收听天数；下面是「随机翻到了 X」小歌单卡（六首随机曲目：立即播放从头播、添加到队列接在队尾、Shuffle 钮换一批，右侧编号列表点行即从该行播，窄窗口自动收起；卡底用强调色 8% 薄罩，与侧栏悬停色一致、随主题联动）、最近播放（八张封面卡单行横排、放不下时横向滚动，节标题右侧有翻页钮，零播放的曲目按入库时间补位）、热门艺术家（前八位歌手圆形大头像、同款单行横排，点到「歌手」详情）与新添加（最近入库的十条曲目，与曲库页相同的曲目列表：双击播放、右键菜单相同）。
- 播放统计按实际播出时长计：默认听到 60% 或 30 秒（任一满足）算一次播放，两个阈值都可在设置 →「播放」→「播放统计」调整（填 0 表示不用该条件）；拖动进度条不算听过。播放记录跟随文件移动 / 改名，删除文件或重建曲库不会清掉历史。

### 曲库

- 支持多个音乐文件夹：用系统文件夹选择器添加，或直接把文件夹 / 音频文件拖进窗口（已在曲库里的会自动定位到它所在的文件夹）。
- 扫描时显示实时进度；可随时「扫描更新」或「重建曲库」（重读全部标签与封面）。
- 文件夹监视（可选）：文件夹里的音频文件增删或改名后，曲库自动更新。
- 艺术家与流派标签分隔符可自定义（支持多个），修改后立即重新拆分（设置 →「其他」）。
- 封面/歌词可以来自曲目同目录的同名图片/lrc（jpg / jpeg / png / webp）或内嵌元数据。
- 过滤低于时长 / 大小阈值的音频，不进曲库。

### 浏览与搜索

- 视图：文件夹、音乐库（全部歌曲）、艺术家（头像网格）、专辑（封面网格）、标签，大曲库也流畅滚动。「音乐库」视图展示全部曲目，页头与列头固定粘滞在顶部，提供「播放全部」便捷操作。
- 侧栏下半部可切换视图：支持在「歌单」、「标签」和「文件夹」之间切换。切换至文件夹或从导航栏进入文件夹模式时，侧栏下半部自动联动为目录树，支持折叠展开、新建/重命名/删除子文件夹以及拖拽移动曲目/文件夹，主视图全宽展示该文件夹直接包含的曲目；操作栏在「播放全部」旁提供「筛选」按钮，点击后展开与智能歌单一致的条件筛选面板（支持「符合以下 全部/任一 条件」模式切换与匹配曲目数统计，支持标题、艺术家、专辑、格式、流派、文件名等多字段多条件配置，按钮变为「清除筛选」可一键清空并收起面板，无匹配时展示空状态提示）；切换至标签或进入标签模式时，侧栏展示流派标签列表并可直接查看各标签曲目；切换至歌单时展示手动与智能歌单。
- 曲目列表双击播放；行尾爱心按钮直接收藏 / 取消收藏。序号列（`#`）只在专辑详情里显示曲目号；设置 →「封面」→「在列表中显示封面」关掉后，曲目表封面列、网格卡片、头像、标签与队列行里的封面位整格移除（不画占位图）。
- 曲目右键菜单：播放、添加到歌单、「编辑元数据…」（弹窗分基础 / 封面 / 歌词三栏：改标题、歌手、专辑、专辑歌手、年份、音轨号 / 碟号、作曲与注释，流派用标签输入器增删（下拉列出曲库已有流派，也可自由新增），封面可选写同名图片文件或内嵌标签、可换可移除，歌词可选写同名 `.lrc` 文件或内嵌标签；保存直接写回文件，原子替换不丢数据，正在播放的曲目保存后自动从原位置续播）、重命名文件（只改主文件名，扩展名不变）、在访达中显示，以及「从曲库中删除」（只删记录与缓存，文件还在时下次扫描会重新入库）和「删除文件…」（确认后移到回收站；设置 →「曲库」→「删除文件」可改成不经回收站直接删除）。
- 「元数据」视图：全库曲目的标签表格（勾选多选、列宽拖拽调整、支持按分组自定义显示列与默认重置、列排序与筛选；点已选中的行可取消它），选中后可单条或批量编辑全部标签字段（含指挥、作词、发行商、版权、评分与 ReplayGain）、更换或移除封面；批量修改提供音轨连续编号与英文大小写格式化工具。单选时右侧面板附音频参数（编码、采样率、位深、比特率、声道、时长、文件大小、修改与入库时间，每项可一键复制），文件名在面板顶栏直接改（铅笔进编辑、只改主干、扩展名不动，同名 `.lrc` 与封面图片一起改名）。支持按模板批量重命名文件：只改文件名、扩展名不变、文件留在原文件夹，同名 `.lrc` 与封面图片一起改名，重名 / 冲突在应用前预先拦截。
- 全局快捷命令面板（Command Palette）：点击侧栏搜索框或使用快捷键（macOS 上为 ⌘K / ⌘F，Windows 上为 Ctrl+K / Ctrl+F）唤出浮动命令面板，支持搜索与直达曲目、页面导航、偏好设置与快捷播放控制，键盘上下键导航、回车确认、Esc 或点遮罩关闭，各项操作旁标注对应快捷键。
- 窗口最小 1000×720，侧栏始终完整展开；界面随窗口宽度自适应：首页与网格的列数、各页边距与元数据面板按可用宽度调整，曲目表的专辑、大小、序号（仅专辑详情）列在过窄时逐级收起，播放条的音量滑条在较窄窗口收成音量键的竖向弹层；全屏播放页的封面随窗口缩放。

### 歌单

- 手动歌单：在曲目上点右键（或全屏页「⋯」）→「添加到歌单」。歌单页里右键可移除；文件被移走后条目保留，回到曲库时重新出现。
- 智能歌单：按条件从曲库自动聚合，曲库变化时跟着更新。条件分元数据（标题、歌手、专辑、专辑歌手、标签、年份）、音频（格式、时长、采样率、比特率、声道数）、文件（文件夹、文件名、大小、修改时间）三组；组合方式为「全部」或「任一」，可排序并限制数量，编辑时实时显示匹配数。
- 侧栏「+」新建；右键歌单可重命名 / 编辑条件、删除（删除前确认，不动文件）。
- 固定的「我喜欢」排在歌单最前；曲目行尾、播放条与全屏页上的心形按钮收藏 / 取消收藏曲目。

### 播放

- 上一首 / 下一首、循环模式、精确跳转；播放键图标在播放三角与暂停竖条之间形变过渡。
- 播放条右侧的队列按钮弹出当前队列，点一首直接跳过去；点外面或 Esc 关闭。
- 淡入淡出（设置里输入 0–5000 毫秒，0 为关闭，默认 200 毫秒）：播放、暂停、切歌、跳转时音量渐变；一首自然播完接下一首时不淡变。
- 曲间无缝：一首自然播完时下一首已预载好、直接接上，中间没有停顿（单曲循环的重复也一样连续）。
- 随机播放时同一歌手的曲目按黄金比例近似均匀摊开，避免连续撞车。
- 输出设备变化（拔下耳机、切换系统默认设备）时自动暂停，可在设置 →「播放」→「输出设备」关闭——关闭后会在新的默认设备上继续播放；设备全部断开时总会暂停。机器本来就没有可用输出设备时（无声卡环境）按静音照播——进度、播放统计与无缝换曲照常推进，设备接回后从当前位置出声。
- ReplayGain：按曲目或按专辑标签调整音量，可设预放大、无标签曲目的增益与防削波（设置 →「播放」，默认关闭）。
- 10 段均衡器（31 Hz–16 kHz，±12 dB）与前级增益：竖排推子、左侧 dB 标尺，内置流行 / 摇滚 / 爵士 / 古典 / 人声 / 低音增强 / 高音增强预设，拖动立即生效（设置 →「播放」→「均衡器」）。
- 记住上次播放：重新打开时恢复曲目、位置和队列。
- 支持系统媒体键与锁屏控制（Now Playing），显示曲名、歌手 / 专辑与封面。Windows 上硬件媒体键随窗口激活归 Zeo（与其他用键盘钩子抢键的播放器并存时，最后聚焦的播放器拿键）。
- 键盘快捷键（窗口聚焦时；macOS 用 ⌘，Windows 对应为 Ctrl）：Space 播放 / 暂停，⌘→ / ⌘← 下一首 / 上一首，⌥⌘→ / ⌥⌘← 快进 / 快退 5 秒（按住连发），⌘↑ / ⌘↓ 音量（按住连发），⌘⏎ 展开 / 收起全屏播放，⌘K 或 ⌘F 命令面板，⌘, 偏好设置，⌘1 – ⌘7 按侧栏顺序切换页面，⌘W 关闭窗口（按「关闭窗口」设置最小化到托盘 / 询问 / 退出）。全部键位可在 设置 →「快捷键」自定义：点击键位胶囊后按下新组合键即改，重复键位顶掉原绑定，Backspace / Delete 清除、Esc 取消，可一键还原默认；「喜欢当前曲目」「切换循环模式」「静音」等默认未绑定的动作也可在这里指定键位。

### 全屏播放

打开时淡入上滑、收起时淡出下滑（跟随系统「减弱动态效果」设置）。

- 列表封面作背景，切歌时平滑过渡；左列大封面、曲名、歌手 / 专辑、音质与流派标签，「⋯」菜单可编辑元数据、在访达中显示、拷贝路径。
- 波形进度条：可点击或拖动跳转。
- 行级歌词：同名 `.lrc` 文件优先，其次内嵌歌词（设置 →「歌词」→「歌词来源」可换成内嵌优先）。当前行自动跟随（停在偏上位置），手动滚动后 3 秒恢复跟随，点击某行直接跳转；左 / 居中 / 右对齐可选（默认左对齐）；歌词区上下边缘淡出，离当前行越远越模糊（鼠标移入时变清晰）；悬停行在行尾显示时间戳（占位不被长歌词盖住，设置 →「歌词」→「歌词行时间戳」可关闭）。
- 歌词偏移：全屏歌词区右缘的竖排控件，± 按钮按 0.5 秒步进调节当前曲目的偏移，点时间值弹出横向滑条可大范围拖动（正值提前、负值延后，±30 秒内，可一键重置），只对这首歌生效并随文件改名/移动保留；设置 →「歌词」→「全局歌词偏移」填毫秒，对所有曲目叠加生效（适合蓝牙耳机等固定延迟）；`.lrc` 文件自带的 `[offset:毫秒]` 标签也会生效。点击歌词行跳转时同样按偏移后的时间定位。
- 键盘：Space 播放 / 暂停，← → 快退 / 快进 5 秒（Shift 为 30 秒，按住连发），↑ ↓ 音量（按住连发），Esc 或 ⌘⏎ 收起；全局快捷键（⌘→ 切歌、⌘↑ 音量等）在全屏里同样生效。

### 外观与字体

- 浅色 / 深色跟随系统，也可在设置 →「外观」固定一种。
- 主题色：设置 →「外观」→「主题色」支持配置「黑白」、「封面」、「自定义」——「黑白」为主体经典的黑白色调；默认「封面」自动跟随当前曲目封面的主色调，同时向界面底色轻调（切歌时 300ms 平滑过渡；黑白封面自动回黑白）；「自定义」支持红 / 橙 / 绿 / 蓝 / 紫等预设强调色与十六进制颜色代码输入。
- 界面字体：设置 →「外观」→「字体」可选系统默认或任一已安装字体，在输入框里输入即过滤、逐字体预览，选一个立即生效；也可直接键入字体名。

### 设置

- 侧栏「设置」打开设置弹窗：左栏是分类与搜索框（直接搜选项），右栏是所选分类的内容；Esc 或点遮罩关闭。

### 托盘

- 第一次点关闭按钮时选择「最小化到托盘」或「退出」，选择会记住（设置 →「窗口」→「关闭窗口时」可改）。
- 最小化后播放继续；托盘图标本身是播放 / 暂停按钮：左键播放 / 暂停，双击图标打开窗口（不触发播放 / 暂停），右键打开菜单（可上一首 / 下一首、打开窗口、退出）。macOS 上是黑白的菜单栏图标；Windows 上悬停图标显示当前曲名 — 歌手；macOS 上从 Dock 点开也恢复窗口。
- 可选「记住窗口大小和位置」：重新打开时恢复上次的窗口（设置 →「窗口」，默认开）。
- 只允许一个实例：已打开时再启动会激活已有窗口（最小化到托盘的也会显示出来）。

### 更新

- 设置 →「关于」里查看版本与项目地址、检查更新：新版本从 GitHub Releases 下载，校验 SHA-256 后原地替换，重启生效（开发运行里没有更新渠道，设置里同样说明）。默认启动时自动检查一次，可关。

## 尚未支持

- Opus 格式、逐字歌词、Linux 版本。

## 构建

需要安装 [NSH](https://nsh.dev) 与 [Rust](https://rustup.rs)：

```sh
nsh run .                          # 本机运行（改代码自动重建）
nsh package . --target macos       # 打包 .app（在 macOS 上）
nsh package . --target windows --icon resources/icon-windows.png   # 打包安装包（在 Windows 上）
```
